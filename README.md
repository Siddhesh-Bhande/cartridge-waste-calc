# Cartridge Waste & Environmental Footprint Calculator

A zero-dependency, client-side calculator designed to model and visualize the cumulative plastic waste, greenhouse gas emissions, and economic costs generated by consumable industrial and commercial printer cartridges.

## Overview

Millions of empty toner and ink cartridges enter municipal landfills each year, each containing up to several pounds of engineering-grade polymers and toxic residual toner. This interactive tool models lifecycle waste trajectories based on fleet size, monthly print volume, and cartridge yield thresholds, helping facilities quantify the environmental ROI of circular recycling programs.

## Key Features

- **Fleet Volume Modeling**: Custom inputs for monthly cartridge replacement velocity, unit costs, and polymer densities.
- **Environmental Metrics**: Dynamically models landfill volume displacement, decomposition half-lives, and CO2 emissions.
- **Zero-Dependency Architecture**: Crafted in pure HTML5, modern vanilla CSS custom properties (Green Suite design system), and performant vanilla JavaScript.
- **Responsive Layout**: Fluid CSS Grid and Flexbox cards designed for responsive viewport scaling without heavy external frameworks.

## Running the Application

Because this application relies solely on native browser APIs, no build steps or dependencies are required:
```bash
# Simply open in any modern browser
open index.html
```
Or serve via any static web server:
```bash
npx serve .
```
